# 重力式 河川パラペット 設計計算書 作成ツール

PDFの見本（L型擁壁の設計計算書）に倣ったレイアウトで、**重力式擁壁**の
河川パラペット設計計算書を作成するブラウザツールです。
Excelライクな表形式で諸条件を入力すると、安定計算・断面照査を行い、
見本様式のA4計算書をプレビュー・PDF出力できます。

## 使い方

ビルド不要。`index.html` をブラウザで開くだけで動作します。

```
# そのままブラウザで開く、またはローカルサーバで配信
python3 -m http.server 8000   # → http://localhost:8000/
```

1. 左パネルの **設計条件 / 形状 / 荷重状態** タブで数値を入力（入力すると即時に再計算）
2. 右側に見本様式の計算書がプレビュー表示されます
3. **PDF出力（印刷）** ボタン → ブラウザの印刷ダイアログで「PDFに保存」（A4）
4. **入力を保存 / 読込** で入力データ（JSON）を再利用できます

## 計算内容

準拠：道路土工 擁壁工指針（平成24年7月, 日本道路協会）の考え方

| 項目 | 内容 |
|------|------|
| 安定計算 | 転倒（偏心量 e≦ea）、滑動（安全率 Fs≧Fsa）、支持（地盤反力 qmax≦qa） |
| 土圧 | 試行くさび法（常時／地震時、地震時の壁面摩擦角δを自動算定） |
| 断面照査 | 重力式（無筋）合応力点の圧縮・引張・せん断応力度照査 |
| 荷重状態 | 常時1・常時2・地震時(L2)・衝突時(防護柵)・満水時（水圧・浮力） |

### 主な計算式

- 転倒：`d=(ΣMr−ΣMt)/ΣV`, `e=B/2−d ≦ ea`
- 滑動：`Fs=(ΣV·μ＋CB·B′)/ΣH ≧ Fsa`（`B′=B−2|e|`）
- 支持：`|e|≦B/6` で台形分布 `q=ΣV/B·(1±6e/B)`、それ以外は三角形分布 `qmax=2ΣV/{3(B/2−|e|)}`
- 土圧：`P = W·sin(ω−φ)/cos(ω−φ−α−δ＋θ)`（θ:地震合震度角、ω:すべり角を探索し最大値）
- 地震時δ：`θ=atan(kh/(1−kv))`, `Δ=asin(sinθ/sinφ)`, `δ=atan[sinφ·sin(θ+Δ)/(1−sinφ·cos(θ+Δ))]`
- 断面：`σ = N/A ± M/Z`（`A=b·1.0`, `Z=b²/6`）

## ファイル構成

```
index.html        画面（入力パネル＋レポートプレビュー）
css/style.css     画面・印刷(A4)スタイル
js/defaults.js    既定の設計データ
js/calc.js        計算エンジン（純粋関数・Nodeでもテスト可）
js/app.js         UI構築・レポート生成・断面図SVG描画
```

## 注意

本ツールは標準的な算定式に基づく実用計算であり、特定の市販ソフトの
出力数値を完全一致させるものではありません。設計成果として用いる際は
適用基準・各種係数・許容値を必ず確認のうえご利用ください。
